## Run Locally

### Prerequisites

* Node.js
* npm
* Git

### Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd mon-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

To build the project for production:

```bash
npm run build
```
